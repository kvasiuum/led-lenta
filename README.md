# Лента — iOS-приложение (Swift / SwiftUI)

Нативная версия пульта LED-ленты LEDDMX (led-lenta.vercel.app). Все функции сайта + то, что умеет только приложение.

## Сборка

**Есть Mac:** открой `Lenta.xcodeproj` в Xcode 26 (или 16), выбери свою команду в Signing, запусти на iPhone.

**Нет Mac:** залей папку в репозиторий GitHub → вкладка Actions → «Build IPA» соберёт неподписанный
`Lenta.ipa` (артефакт `Lenta-ipa`). Установи его через SideStore или iLoader — они подпишут твоим Apple ID.
Ставь отдельным приложением, **не внутрь LiveContainer**: там нет разрешений на Bluetooth и микрофон.

## Что внутри 

- **Bluetooth** — CoreBluetooth, без Bluefy. Сам подключается к ленте, которая хоть раз подключалась:
  при запуске, при возврате в приложение, после обрыва, даже если iOS «забыла» ленту (ищет по имени). Сервис FFE0, запись в FFE1 без ответа, команды 7B…BF,
  порядок GRB, гамма 2.2. Сам подключается к прошлой ленте, переподключается при обрыве, список найденных устройств.
- **Цвет** — круг (оттенок/насыщенность), 16 цветов, яркость, порядок каналов, «Проверка: красный».
- **Музыка** — три вкладки:
  - **Треки**: свои файлы и ссылки SoundCloud, Spotify, Яндекс Музыки в одной библиотеке.
    «Выбрать» → собрать плейлист из выбранных, добавить в плейлист, удалить.
  - **Плейлисты**: свои и перенесённые по ссылке (SoundCloud, Spotify, Яндекс; плейлисты и альбомы).
    Можно смешивать треки разных сервисов, переставлять, переименовывать.
  - **Микрофон**: свет по звуку в комнате, работает вместе с любым плеером.
  Свои файлы разбираются заранее — свет точно в такт. SoundCloud — по форме волны и темпу.
  Spotify и Яндекс играют во встроенных плеерах этих сервисов: без входа Spotify даёт 30-секундные
  отрывки, после входа с Premium — полные треки; свет у них ровным ритмом или по микрофону.
- **Режимы** — 210 эффектов, избранное, автосмена каждые 10 с.
- **Таймер** — сон 15–120 мин, расписание по дням, «Работать в фоне».
- **Плеер** — одна очередь на все сервисы; мини-полоска и полный экран в стиле экрана блокировки,
  перемешать / повтор (выкл → плейлист → трек), экран блокировки и пульт наушников.
- **Дизайн** — как на сайте: шапка с лентой, переключатель разделов со скользящей плашкой; Liquid Glass на iOS 26, матовое стекло на iOS 17–18; фон из цвета ленты и обложки.

Минимум iOS 17. Настройки хранятся с префиксом `lenta.`.

## Автообновление через SideStore

После каждого коммита GitHub Actions собирает `Lenta.ipa`, выпускает его в Releases (версия 1.0.N)
и обновляет `apps.json` — источник для SideStore.

1. Репозиторий должен быть **публичным** — иначе SideStore не скачает файлы.
2. SideStore → «Источники» → «+» → вставь:
   `https://raw.githubusercontent.com/kvasiuum/led-lenta/refs/heads/claude/loving-wright-wt954c/apps.json`
   (или в приложении внизу страницы: «Обновления через SideStore»).
3. Установи «Ленту» из этого источника. Новые версии появятся в SideStore → «Мои приложения» → «Обновить»;
   приложение само покажет плашку «Доступна версия…».

Если поменяешь ветку или имя репозитория — поправь `LentaSourceURL` в `Lenta-Info.plist`.

## Android (APK)

Папка `android/` — оболочка (Trusted Web Activity) для сайта led-lenta.vercel.app: открывает его через
Chrome без адресной строки, поэтому работает Web Bluetooth. Сайт обновляется сам — APK пересобирается
только при изменениях в `android/` (workflow «Build APK», выпуск `android-v1.0.N` в Releases).

- Секреты репозитория: `ANDROID_KEYSTORE_B64` и `ANDROID_KEYSTORE_PASSWORD` (ключ подписи; без него APK
  подписан отладочным ключом и обновления не встанут поверх).
- `.well-known/assetlinks.json` нужно выложить на сайт (вместе с `index.html` на Vercel) —
  тогда в приложении не будет адресной строки.
- Автообновления APK: приложение Obtainium → добавить репозиторий kvasiuum/led-lenta.
- Компьютер: сайт в Chrome/Edge → «Установить приложение» в адресной строке.
