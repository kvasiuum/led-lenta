# Лента

Пульт LED-ленты LEDDMX по Bluetooth. В репозитории три части:

| Что | Где | Платформа |
|---|---|---|
| Сайт (оригинал) | `index.html` → [led-lenta.vercel.app](https://led-lenta.vercel.app) | Любой браузер с Web Bluetooth: Chrome/Edge на Android и компьютере |
| iOS-приложение (Swift / SwiftUI) | `Lenta/`, `Lenta.xcodeproj` | iPhone и iPad, iOS 17+ |
| Android-приложение | `android/` | Android 6+, нужен Chrome |

## Установка

**iPhone.** SideStore → «Источники» → «+» → вставь
`https://raw.githubusercontent.com/kvasiuum/led-lenta/refs/heads/claude/loving-wright-wt954c/apps.json`
→ установи «Ленту». Обновления потом появятся в SideStore → «Мои приложения» → «Обновить»,
а приложение само покажет плашку «Доступна версия…». Ссылку на источник можно скопировать и в приложении:
внизу страницы «Обновления через SideStore».
Ставь отдельным приложением, **не внутрь LiveContainer**: там нет доступа к Bluetooth и микрофону.

**Android.** [Releases](https://github.com/kvasiuum/led-lenta/releases) → последний `android-v1.0.N` →
`Lenta.apk`. Автообновления — через приложение Obtainium (добавить репозиторий `kvasiuum/led-lenta`).

**Компьютер.** Открой сайт в Chrome/Edge → «Установить приложение» в адресной строке.

## iOS-приложение: что умеет

- **Bluetooth** — CoreBluetooth, без Bluefy. Сервис FFE0, запись в FFE1 без ответа, команды 9 байт `7B…BF`,
  порядок каналов GRB, гамма 2.2. Сам подключается к ленте, которая хоть раз подключалась: при запуске,
  при возврате в приложение, после обрыва, даже если iOS «забыла» ленту (ищет по имени).
  iOS может сама поднять приложение в фоне, когда лента снова рядом.
- **Цвет** — круг (оттенок и насыщенность), 16 цветов, яркость, порядок каналов, «Проверка: красный».
- **Музыка** — три вкладки:
  - **Треки** — свои файлы и ссылки SoundCloud, Spotify, Яндекс Музыки в одной библиотеке.
    Зажми трек и перетащи, чтобы поменять порядок. «Выбрать» → новый плейлист из выбранных,
    добавить в плейлист, удалить.
  - **Плейлисты** — свои и перенесённые по ссылке (плейлисты и альбомы SoundCloud, Spotify, Яндекса).
    Можно смешивать сервисы, переставлять треки, переименовывать.
  - **Микрофон** — свет по звуку в комнате, работает вместе с любым плеером.
- **Светомузыка** — Радуга / Мой цвет / Вспышки, чувствительность к биту (80–200 Гц), плавность,
  «Свет раньше на» (0–400 мс) — подстройка под задержку ленты.
  Свои файлы разбираются заранее — свет точно в такт; SoundCloud — по форме волны и темпу;
  Spotify и Яндекс — ровным ритмом или по микрофону.
  Считается на отдельном потоке с вертикальной синхронизацией (CADisplayLink, 60–120 Гц),
  в фоне — таймер каждые 8 мс; удар уходит на ленту сразу.
- **Spotify и Яндекс** играют во встроенных плеерах этих сервисов. Без входа Spotify даёт 30-секундные
  отрывки, после входа с Premium — полные треки. Список треков Яндекса берётся из неофициального API;
  из-за границы Яндекс может не отвечать.
- **Режимы** — 210 эффектов, избранное, автосмена каждые 10 с.
- **Таймер** — сон 15 мин – 2 часа, расписание по дням недели, «Работать в фоне».
- **Плеер** — одна очередь на все сервисы. Внизу карточка как на сайте; без касаний через 5 с
  сворачивается в полоску (назад · play · вперёд). Перемешать, повтор (выкл → плейлист → трек),
  полный экран, экран блокировки и пульт наушников.
- **Дизайн** — как на сайте: стекло с бликом, переключатели со скользящей плашкой, белая основная кнопка,
  фон из цвета ленты и обложки.

Настройки хранятся в UserDefaults с префиксом `lenta.`.

## Сборка

Всё собирается в GitHub Actions на каждый коммит — Mac не нужен.

| Workflow | Когда | Результат |
|---|---|---|
| **Build IPA** (`macos-15-intel`) | любой коммит, кроме `android/`, `.well-known/`, `*.md` | Releases `v1.0.N` → `Lenta.ipa` (без подписи), обновлённый `apps.json` |
| **Build APK** (`ubuntu-latest`) | изменения в `android/` или вручную (Run workflow) | Releases `android-v1.0.N` → `Lenta.apk` |

Есть Mac — можно открыть `Lenta.xcodeproj` в Xcode 26 (или 16), выбрать свою команду в Signing и запустить на iPhone.

### Однократная настройка

- Репозиторий **публичный** — иначе SideStore не скачает IPA и `apps.json`.
- Секреты (Settings → Secrets and variables → Actions): `ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`.
  Ключ `lenta-release.jks` хранить у себя и **не класть в репозиторий**: без него обновление APK не встанет поверх.
- `.well-known/assetlinks.json` выложить на Vercel рядом с `index.html` — тогда в Android-приложении
  не будет адресной строки.
- Сменил ветку или имя репозитория — поправь `LentaSourceURL` в `Lenta-Info.plist`.

### Если что-то не так

- **Скрытые папки** (`.github`, `.well-known`) через «Upload files» не загружаются — создавай и правь их
  на GitHub через «Add file → Create new file» или карандаш.
- **Сборка висит в очереди** («Waiting for a runner») — у GitHub не хватает macOS-машин; помогает
  `runs-on: macos-15-intel` или просто подождать.
- **Сборка упала** — в запуске скачай артефакт `build-log` (iOS) или раскрой красный шаг (Android).

## Структура iOS-кода

```
Lenta/
  Core/        Services (все модели), AppModel (цвет, питание, режимы), Library (треки и плейлисты),
               Updates (проверка обновлений), Prefs, ColorMath
  Bluetooth/   LEDController — подключение, очередь записи, автоподключение
  Audio/       LightEngine (светомузыка), StreamAnalyzer (FFT + бас), FileAnalysis, MicListener,
               LocalLibrary (воспроизведение файлов), MusicModel
  SoundCloud/  WebPlayer (встроенные плееры SC/Spotify/Яндекс), Importer (ссылки), Waveform
  Player/      PlayerController — очередь, перемешать/повтор, экран блокировки
  Timer/       TimerModel — сон и расписание
  Views/       экраны и общие стили (Glass.swift)
scripts/make_source.py   — генерирует apps.json для SideStore
```
